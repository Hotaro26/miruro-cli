# Miruro CLI Tool

A lightweight command-line interface for searching anime on Miruro.bz and extracting streaming manifests for playback in MPV.

## How it Works

1.  **Frontend Search**: To avoid unstable API endpoints that frequently return 410 errors, this tool uses **Playwright** to interact directly with the Miruro search page. It extracts the official anime IDs from the UI.
2.  **Dynamic Extraction**: The tool navigates to the selected anime's watch page and monitors network traffic to capture `.m3u8` (HLS) master playlists generated by the site's video player.
3.  **MPV Integration**: Since Miruro's streaming servers require specific security headers, the tool automatically generates a pre-formatted `mpv` command with the correct `--referrer` and `--user-agent` flags.

## Prerequisites

- Python 3.8+
- [MPV Player](https://mpv.io/) installed and in your system PATH.

## Installation

1. Clone or download this folder.
2. Install the required Python libraries:
   ```bash
   pip install -r requirements.txt
   ```
3. Install the Playwright browser binaries:
   ```bash
   playwright install chromium
   ```

## Usage

Run the script and follow the on-screen prompts:
```bash
python main.py
```
